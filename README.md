# TunnelVision

[![Build](https://github.com/TunnelVisionMod/TunnelVision/actions/workflows/build.yml/badge.svg)](https://github.com/TunnelVisionMod/TunnelVision/actions/workflows/build.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

A client-side Fabric mod for Minecraft 26.1.2.

## Requirements

- Minecraft 26.1.2
- [Fabric Loader](https://fabricmc.net/use/) 0.19.5+
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)

## Installation

Download the latest jar from [Releases](https://github.com/TunnelVisionMod/TunnelVision/releases) and put it in your `.minecraft/mods` folder together with the required mods.

## Building

Requires JDK 25.

```sh
./gradlew build
```

The jar ends up in `build/libs/`.
